Vector graphics describe an image as a set of shapes: points joined by straight lines and curves, each shape filled with a color or a gradient. Because the file stores the geometry rather than the finished picture, a vector image can be drawn at any size, from a favicon to a billboard, and stay perfectly sharp.

Most images you meet day to day are the other kind: **raster** images, such as PNG, JPEG and WebP files, which store a fixed grid of colored pixels.

## Pixels vs shapes

A raster image is a mosaic. A 512 × 512 PNG holds exactly 262,144 pixels, and that is all the detail it will ever have. Enlarge it and each pixel simply gets bigger: edges turn into staircases, or into a soft blur if the software smooths them.

A vector image is a recipe. Instead of storing which pixels are blue, it stores something like *"start here, curve through these points, close the shape, fill it blue."* Whatever draws the image, a browser, a design app, a printer, follows the recipe at the size it needs, so edges are always as crisp as the screen or the paper allows.

## How a vector shape is built

Every vector shape is a **path**:

- **Anchor points** mark where the outline goes.
- **Segments** join the anchor points, either straight lines or **Bézier curves**.
- **Handles** (control points) pull on a curve to set how it bends, without lying on the outline themselves.
- A **fill** colors the inside, and an optional **stroke** draws along the outline.

Shapes are drawn in order, so a later shape can sit on top of an earlier one. A whole illustration is simply many paths stacked in the right order. You can see exactly this in [What is SVG?](/kb/what-is-svg)

## Raster vs vector at a glance

| | Raster (PNG, JPEG, WebP) | Vector (SVG, AI, EPS, PDF) |
| --- | --- | --- |
| Stores | A grid of pixels | Shapes, curves and fills |
| Enlarging | Blurs or shows pixels | Stays sharp at any size |
| Editing | Paint over pixels | Select, move and recolor whole shapes |
| File size | Grows with resolution | Grows with the number of shapes |
| Best for | Photos, textures, painted detail | Logos, icons, illustration, type, anything cut or printed large |

## What vector graphics are good at

- **Any size from one file.** A logo drawn once works on a business card, a website and the side of a van.
- **Editing.** Each shape is still a shape. Recolor it, move it, delete it, or reuse it in another design.
- **Small files for flat artwork.** A logo with a handful of colors is often a few kilobytes as a vector, and the size does not change when it is printed bigger.
- **Machines that follow paths.** Cutting plotters, laser cutters, CNC routers and embroidery machines need outlines to follow, and only a vector has them. More on this in [Why convert a JPEG or PNG to vector?](/kb/why-convert-images-to-vector)

## Where raster still wins

Vectors are not better at everything. A photograph has a different color in almost every pixel, with soft focus, grain and texture, and describing all of that as shapes takes an enormous number of them. Photos, scans of paintings and anything with fine texture are usually best left as raster images.

The interesting middle ground is artwork that *looks* like it should be a vector but only exists as pixels: a logo saved as a PNG, a cartoon generated by an AI model, a scanned sketch. That is what vector tracing is for. See [How vector tracing works](/kb/how-vector-tracing-works).

## Common vector formats

- **SVG** (Scalable Vector Graphics): the open web standard, readable by every browser and design tool. It is what VTracer produces. [What is SVG?](/kb/what-is-svg)
- **AI**: Adobe Illustrator's own format.
- **EPS**: an older PostScript-based format still requested by some print shops.
- **PDF**: can hold vector artwork as well as text and images; common for print.
- **DXF**: a CAD format, often used for laser cutting and CNC.

Most design apps convert freely between these, so an SVG is a safe starting point for all of them.
